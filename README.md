# CyberSafe Uganda

CyberSafe Uganda is a responsive cybersecurity awareness website designed to educate users about online safety and digital security. The project provides information on common cyber threats, password security, phishing prevention, safe browsing practices, and privacy protection.

## Features
- Responsive and modern user interface
- Cybersecurity awareness resources
- Password security guidance
- Safe browsing tips
- Cyber threat information
- Contact page
- Image gallery

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Purpose
The goal of this project is to promote cybersecurity awareness by providing easy-to-understand information that helps users protect themselves against common online threats.

## Future Improvements

- Blog and news section
- Admin dashboard
